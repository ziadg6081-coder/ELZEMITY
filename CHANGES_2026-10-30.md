# Changes — 2026-10-30

- Customers and staff displayed in separate panels in Admin > Users.
- Only logged-in `admin` can access admin user management API.
- New admin-created accounts can only be `order_manager` or `inventory_manager`; never `customer` or `admin`.
- Existing customers cannot be promoted; existing admin accounts cannot have their role changed from this API. Staff can change only between the two staff roles.
- Admin direct password changes are blocked for customer/admin accounts; these accounts use the email reset flow.
- Customer registration remains customer-only.
- Guest checkout was **already supported** in the uploaded code; preserved unchanged.
- Account header changed to black outline icon; cart count overlays the bag instead of sitting beside it.
- No SQL schema changes or migrations required. Existing database and orders remain untouched.
- Do not run npm run setup or npm run migrate on an existing installation. Back up database before deploying.
- This is a code update; live database/integration testing was not possible in this environment.
