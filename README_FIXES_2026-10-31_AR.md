# ELZEMITY — تحديثات 31 أكتوبر 2026

## ما تم تعديله
- إزالة قيد 10 وحدات للمنتج الواحد في السلة والـ API، ورفعه إلى 50 وحدة كحد أقصى للسطر الواحد (الحد الموجود بالفعل في قيد قاعدة البيانات `order_items`)، مع الالتزام بالمخزون الفعلي. لا يوجد حد شراء ثابت بقيمة 10,000 جنيه في التطبيق.
- توسيع التحقق من مبالغ التحويل والأسعار حتى حدود الأعمدة المالية الحالية `DECIMAL(10,2)` (أقصى قيمة 99,999,999.99 جنيه للحقل الواحد)، مع خطأ مفهوم إذا تجاوز إجمالي الطلب سعة قاعدة البيانات. أي حدود تحويل يفرضها البنك أو InstaPay ليست تحت تحكم الموقع.
- عند اختيار الدفع الكامل مقدمًا، يُسجّل المبلغ كمدفوع بالكامل بمجرد اعتماد التحويل الصحيح من الأدمن. لا يظهر زر تحصيل عند الاستلام لهذا النوع من الطلبات، ولا يُنشأ تحصيل نقدي وهمي. الدفع عند الاستلام يظل كما هو.
- إصلاح القيمة الافتراضية لخانة مبلغ مراجعة التحويل: الإجمالي الكامل للطلب عند الدفع الكامل، والشحن فقط عند اختيار الشحن مقدمًا.
- احتساب قيمة التحويل الكامل المعتمدة بشكل صحيح في إجمالي الأموال المحصلة بالتقارير، دون جمعها مرة ثانية كتحصيل عند الاستلام.
- عرض تفاصيل سجل العمليات وتاريخ الطلب بشكل مقروء بدل JSON الخام، مع الإبقاء على البيانات المسجلة في MySQL كما هي.
- تصغير زر تغيير اللغة قليلًا وتكبير زر البحث في واجهة المتجر.

## التشغيل على قاعدة البيانات الأساسية
1. احتفظ بنسخة احتياطية حديثة من قاعدة البيانات الأساسية ومن مجلد المشروع الحالي قبل الاستبدال.
2. لا تستورد ملفات SQL أو النسخ الاحتياطية المرفقة فوق قاعدة البيانات الأساسية.
3. تأكد أن ملف `backend/.env` الموجود على جهازك يشير إلى `DB_NAME=oriantal_perfumes`، ولا تشارك ملف `.env` أو النسخة الاحتياطية علنًا.
4. هذه التعديلات لا تتطلب أي `ALTER TABLE` جديد إذا كان العمودان `products.fragrance_notes` و `orders.customer_note` موجودين بالفعل (كما أكدت فحوصك الأخيرة).
5. **لا تشغّل** `npm run setup` أو `npm run migrate` أو `npm run seed` على قاعدة البيانات الأساسية: تعارض checksum الخاص بـ migration 005 كان موجودًا قبل هذا التحديث، ولم نغيّر ملفات migrations أو سجلها.
6. أوقف السيرفر القديم (`Ctrl+C`) وشغّل النسخة الجديدة من مجلد `backend` باستخدام `npm start`.
7. حدّث المتصفح تحديثًا إجباريًا (`Ctrl+Shift+R`) وجرّب: طلبًا فوق 10,000 جنيه بمخزون كافٍ، وطلب دفع كامل، وطلب شحن فقط، ومراجعة سجل العمليات.
