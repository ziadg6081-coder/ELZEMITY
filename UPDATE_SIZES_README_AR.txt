ELZEMITY — تحديث إضافة الأحجام والأسعار

التعديل يشمل 3 ملفات فقط:
- frontend/js/admin.js
- frontend/css/admin.css
- backend/server/routes/admin.js

لتطبيق التعديل على مشروعك المحلي:
1) خذ نسخة احتياطية من ملفات المشروع الحالية.
2) فك ضغط ملف PATCH، وانسخ الملفات الثلاثة إلى نفس مساراتها في مشروعك الأصلي مع الموافقة على الاستبدال.
3) أعد تشغيل Node.js (من داخل backend: npm start).
4) افتح لوحة الأدمن، ثم أضف منتجًا أو عدّل منتجًا قائمًا.
5) عند حجم واحد: املأ صف الحجم والسعر فقط.
6) عند عدة أحجام: اضغط + إضافة حجم، واكتب الحجم وسعره في صف مستقل.
7) السعر القديم اختياري؛ اتركه فارغًا لو مفيش خصم.
8) أول حجم هو الحجم/السعر الأساسي للمنتج.

ملاحظات:
- لا توجد تغييرات على مخطط قاعدة البيانات أو على الطلبات أو حركة المخزون.
- المخزون في النظام الحالي مشترك بين أحجام المنتج، وليس مخزونًا منفصلًا لكل حجم.
- احفظ نسخة من قاعدة البيانات قبل أي تعديل في المنتجات الحقيقية.
- النسخة CLEAN لا تحتوي على .env أو node_modules أو السجلات أو نسخ قاعدة البيانات الخاصة.
- لم يتم إجراء اختبار تكاملي مع MySQL حقيقية في بيئة المستخدم؛ تم التحقق من صياغة JavaScript واختبارات منطق إدخال الأحجام.
